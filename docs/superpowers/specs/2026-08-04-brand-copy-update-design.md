# 下载器品牌与文案更新设计

## 目标

在不改变页面布局、视觉主题、动效和下载功能的前提下，更新下载器页面的品牌标识、浏览器标签页标题、Hero 说明和页脚署名。

## 修改范围

仅修改 `templates/index.html` 中的四处静态文案：

1. 左上角品牌由 `YD / DOWNLOADER` 改为 `MARK YANG / DOWNLOADER`。
2. 浏览器标签页标题改为 `YTB / Ins Downloader - Designed By Mark Yang`。
3. Hero 说明改为两行：
   - 第一行：`最高质量视频，或最高音质音频下载。`，整行保持强调样式。
   - 第二行：`粘贴链接，其余交给下载队列。`
4. 页脚改为 `请仅下载自己拥有权利、获得授权或平台允许下载的视频或音频。 -- Kozeki Ui`。

## 实现方式

- 保留现有品牌容器结构，将方框内的 `YD` 更新为 `MARK YANG`，右侧继续显示 `/ DOWNLOADER`。
- 使用 HTML `<br>` 明确 Hero 文案的两行边界，避免依赖视口宽度自动换行。
- 不新增 CSS、JavaScript、后端接口或第三方依赖。

## 验收

- 自动测试验证四处新文案存在，旧标题和旧品牌文案不存在。
- Hero 文案包含明确换行标签，并且第一行保持强调样式。
- 现有完整测试套件继续通过。
