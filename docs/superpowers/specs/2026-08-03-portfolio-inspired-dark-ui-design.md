# Portfolio 风格深色下载页设计

## 目标

将当前 YouTube/Instagram 下载页升级为参考隔壁 `Portfolio` 项目的高级深色工具界面。页面采用马石油绿、石墨表面、细边框、环境光和克制滚动动效，同时完整保留视频与 MP3 音频下载行为。

## 视觉方向

采用已确认的 `A1 · Editorial Tool + Metrics Band`：

- 深色画布使用 `#0F172A` 与更深的 `#0B1222`。
- 石墨表面使用 `#111827`，悬停表面使用 `#162033`。
- 主色使用马石油绿 `#009B95`，高亮使用 `#00A19B`。
- 文字使用 `#F8FAFC`，次要文字使用 `#94A3B8`。
- 细边框、低透明度网格、柔和环境光和轻微噪点营造技术工具质感，避免霓虹和赛博朋克风格。

## 页面结构

### 顶部状态栏

- 左侧显示 `YD / DOWNLOADER`。
- 右侧显示绿色状态点与 `READY`。
- 不显示 `LOCAL SERVICE · 8233`。
- 页面滚动后，顶部栏切换为半透明深色背景、细边框、阴影和模糊效果。

### Hero

- 技术标签显示 `YOUTUBE + INSTAGRAM / ONLINE`。
- 主标题显示 `Capture. Convert. Keep.`。
- 中文说明保留最高质量视频与最高音质 MP3 的功能描述。
- 背景包含低透明度网格、马石油绿环境光与几何轨道。

### 运行指标带

- `ACTIVE`：当前 `status == "downloading"` 的任务数。
- `QUEUE`：当前 `status == "pending"` 的任务数。
- `LIMIT`：固定显示已确定的并发上限 `03`。
- 无任务时显示 `00 / 00 / 03`。
- 轮询返回批次状态后，由前端从任务数组实时计算 Active 与 Queue。
- 移动端保持三等分紧凑指标行。

### 下载工作区

- 视频和音频继续使用两个独立输入框。
- 桌面端双栏并排，移动端上下排列。
- 两个功能统一采用马石油绿，并通过 `01 / VIDEO`、`02 / AUDIO`、标题和图标区分。
- 输入框使用深色内嵌表面、细边框和聚焦绿光。
- 主按钮使用实心马石油绿，次按钮使用透明描边。
- 保留现有输入框、按钮和任务容器 ID，避免破坏下载逻辑与测试接口。

### 任务区

- 任务列表使用深色技术面板，不再使用白色卡片。
- 等待、下载、完成和失败状态使用左侧细线、状态点与文字区分。
- 保留标题、URL、进度、速度、预计剩余时间、结果元数据、保存路径及错误信息。
- 完成态使用克制绿色；失败态使用红色，维持可辨识性。

## 动效

- 页面顶部显示 2px 马石油绿滚动进度线。
- Hero 状态标签、标题和说明首次加载时分层淡入并上移约 18px。
- 指标带、下载区和任务区进入视口时触发一次 Reveal 动画。
- 精细指针设备启用低透明度指针柔光；触屏设备禁用。
- 卡片悬停轻微上移、边框变绿并增加柔和阴影。
- 按钮箭头悬停时轻微向右下移动，按下时产生 1px 位移反馈。
- Active 与 Queue 数值变化时短暂增强亮度。
- 新任务卡轻微淡入，现有下载状态点与加载动画继续工作。
- 滚动和指针更新通过 `requestAnimationFrame` 调度。

## 无障碍与降级

- `prefers-reduced-motion: reduce` 关闭平滑滚动、位移动画、指针柔光和循环装饰动画。
- 键盘焦点统一使用清晰的马石油绿轮廓。
- 深色背景上的正文、输入、状态和错误信息保持足够对比度。
- JavaScript 不可用时所有正式内容默认可见。
- 不支持 `IntersectionObserver` 时直接显示 Reveal 区块。
- 不支持 `backdrop-filter` 时顶部栏使用不透明深色背景。
- 动效初始化失败不得阻断下载提交、轮询或结果渲染。

## 实现边界

- 正式页面改动集中在 `templates/index.html`。
- 不修改 Flask API、下载器、任务并发和媒体下载行为。
- 不引入 Tailwind、React、动画库、Web 字体或第三方前端依赖。
- `.superpowers/` 加入 `.gitignore`，视觉伴侣产物不进入项目提交。

## 测试与验收

- 自动测试覆盖深色主题与马石油绿变量。
- 自动测试覆盖 Active、Queue、Limit 初始值和实时计算逻辑。
- 自动测试覆盖滚动进度、Reveal、指针柔光与 reduced-motion 降级。
- 现有视频/音频独立输入、按钮互斥、结果渲染、进度显示和移动端长路径测试继续通过。
- 运行完整 Python 单元测试与 `compileall`。
- 在默认 `8233` 端口启动页面，完成桌面和 390px 移动端视觉 QA。
- 浏览器验收覆盖滚动、悬停、键盘焦点、控制台错误、任务状态和横向溢出。
