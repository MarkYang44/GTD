# 局域网 Web 访问设计

## 目标

让同一局域网内的设备通过本机局域网 IP 和端口 `8233` 访问 Web 下载界面。

## 设计

- Flask 监听地址由 `127.0.0.1` 改为 `0.0.0.0`，端口继续使用 `8233`。
- 启动提示同时显示本机地址 `http://127.0.0.1:8233`，并提示局域网设备使用 `http://<本机局域网 IP>:8233`，避免把不可作为客户端目标的 `0.0.0.0` 展示成访问地址。
- README 同步说明局域网访问、macOS 防火墙、访客网络隔离与安全边界。
- 不增加登录认证、TLS、端口映射或公网访问功能。

## 安全边界

- 局域网内任何能连接本机 `8233` 的设备都可以提交下载任务。
- 下载和文件夹路径始终属于运行 Flask 服务的 Mac。
- 不应在路由器上将 `8233` 映射到公网。

## 验证

- 配置测试固定 `WEB_HOST == "0.0.0.0"`、`WEB_PORT == 8233` 和 README 文案。
- 全量单元测试、Python 编译和 JavaScript 语法检查通过。
- 重启前按命令与 cwd 确认旧服务属于本项目；不停止其他进程。
- 启动后确认 `8233` 监听于所有 IPv4 接口，并从回环地址及本机局域网 IP 获取 HTTP 200。
