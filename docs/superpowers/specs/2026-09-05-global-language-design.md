# GTD 全站中英文切换设计

状态：待用户确认，尚未修改功能代码。

## 目标

让下载首页 `/`、使用说明 `/guide`、冠军档案 `/kozekilmu`、赛道指南 `/kozekilmu/tracks` 使用同一语言切换组件和同一偏好。外观沿用现有赛道指南的中文 / EN 滑块，置于各页右上角。默认中文；切换后立即生效，刷新、页面跳转及同源其他标签页同步选择。

## 实现方案

推荐提取共享语言脚本、样式和 Jinja 开关组件，复用赛道指南现有双语内容标记。页面短文案使用明确的翻译键或双语标记；动态文案使用带参数的翻译函数，不做 DOM 文本搜索替换。沿用现有静态页面和 Flask 架构。

备选为服务端按语言重新渲染整页，结构直观，但切换时需额外维护表单及任务状态；另一个备选为每页独立开关，改动较分散且容易出现偏好不同步。采用共享客户端方案。

统一偏好使用全站 localStorage 键，首次读取时兼容已有赛道指南语言设置。head 中尽早设置语言，避免刷新语言闪烁。存储不可用时仍可切换当前页面。开关支持键盘操作，更新 html lang、页面标题、alt、aria-label、title 和 placeholder。

## 页面范围

- 首页：静态文案、输入提示、格式说明、目录选择提示、合集预览、任务状态、按钮、汇总、速度与 ETA 标签，以及应用生成的错误说明和操作建议。
- 切换语言不清空输入、不更改选中条目、不重新提交下载、不打断轮询。重新渲染动态文案时保留当前任务状态；语言应参与渲染更新判断。
- 使用说明：新增完整英文 Markdown 正文，继续使用现有安全渲染器；切换正文时更新目录及有效锚点，保持动画系统正常工作。
- 冠军档案：标题、叙述、导航、图片描述与辅助标签完整双语化。图片和截图保持原始内容。
- 赛道指南：保留现有赛道、车型推荐及翻译，接入共享偏好与组件。
- 用户输入、源站媒体标题、文件路径及第三方原始诊断不自动翻译；应用自身的错误码对应说明提供双语版本，未知诊断提供本地化通用提示并保留原始详情。

GTD — Generalized Transmedia Downloader 和 Designed by Mark Yang 保持固定英文；保留现有路由、彩蛋入口、赛道指南在冠军档案之前的导航顺序以及深色视觉风格。
