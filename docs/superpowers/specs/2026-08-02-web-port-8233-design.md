# Web 默认端口 8233 设计

## 目标

将项目 Web 服务的默认监听端口从 5000 改为 8233，同时保持 `venv/bin/python app.py` 的启动方式不变。

## 设计

- 在 `app.py` 定义 `WEB_HOST = "127.0.0.1"` 与 `WEB_PORT = 8233`，终端提示和 `app.run()` 共用这些常量，避免显示地址与实际监听端口不一致。
- `README.md` 中所有当前操作地址、示例输出和端口排错说明统一改为 8233。
- 历史设计/计划文档保持原样，不改写历史记录。
- 测试覆盖应用默认端口和 README 地址。

## 验收

- 端口测试先在旧实现上失败，再在新实现上通过。
- 完整单元测试与 `compileall` 通过。
- Flask 路由测试客户端继续正常响应；端口变更不影响 API 行为。
