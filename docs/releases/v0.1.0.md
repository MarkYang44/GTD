## GTD 0.1.0

The first GTD desktop release brings the existing YouTube, Instagram, and Bilibili download engine to Windows x64 and macOS Apple Silicon.

- Preview playlists and collections, choose entries, and submit batches with audio, subtitle, and danmaku options.
- Track active tasks and history with progress, transfer speed, retry, cancel, and redownload controls.
- Extract a source audio track or MP3 from a local video. Use the native picker to select input files, output folders, and per-platform Netscape cookies.
- Switch between English and Simplified Chinese and use light, dark, or system appearance.

The desktop app bundles Python, yt-dlp, FFmpeg, ffprobe, Node.js, and aria2. The Web and command-line editions remain available from the same source tree.

首个桌面版本支持 Windows x64 和 macOS Apple Silicon，提供合集选择、批量队列、历史记录、本地音频提取和原生文件选择。客户端内置媒体工具，支持中英文和跟随系统的主题。Web 与 CLI 仍可从源码运行。
