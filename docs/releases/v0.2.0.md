## GTD 0.2.0

GTD 0.2.0 redesigns the desktop app around one list for every download, so adding, watching and finding work no longer means switching between pages.

- One downloads list covers every stored batch. The sidebar filters it to In progress, Queued, Needs attention, Completed or Cancelled with live counts, finished work is grouped by day, and search finds titles, links and file names across all batches.
- Paste links or share text at the top of the list and press Enter. Choose video or audio, the audio format, subtitles and danmaku, turbo mode and the output folder from compact menus; GTD remembers them between launches. Paste anywhere in the window with ⌘V or Ctrl+V, or drag links in from a browser.
- Extract audio from a local video with From file (⌘O or Ctrl+O) in the same place you add links.
- Right-click a task, or use its ⋯ menu, to show the file in its folder, copy the path or link, open the source page, retry, cancel, download again or jump to its batch. Select several tasks with ⌘/Ctrl-click, Shift-click or the keyboard to act on them together.
- Failed tasks gather under Needs attention with the cause and a suggested fix. Sign-in and folder errors link straight to the setting that resolves them, and failures you don't need can be dismissed, with undo.
- Batches keeps each submission with its format, subtitle and turbo settings, its folder and a Retry failed action.
- Settings save as soon as they change and include a keyboard shortcut list, the app version and a shortcut to the app data folder.

GTD 0.2.0 以统一的下载列表重新设计了桌面版：侧边栏按状态筛选并显示实时数量，已完成的任务按日期归档，可跨全部批次搜索。在列表顶部粘贴链接后按回车即可下载，格式、字幕、极速和保存位置等选项会被记住；也可以在窗口任意位置粘贴或拖入链接，或用“从文件”提取本地视频的音轨。任务支持右键菜单、多选与批量操作；失败任务会给出原因和修复入口，也可以忽略并撤销。批次页保留每次提交的设置，设置页新增快捷键一览、版本号和应用数据文件夹入口。
